- `npm run typecheck`：型検査。
- `npm test`：9件。日付精度、うるう年、正式締切の出典要件、準備と締切の独立、所有者権限、閲覧者投影、面談用投影、同期マーカー、日またぎ・複数日予定、文字コントラストを確認。
- Sitesのビルドヘルパー：Workerとクライアントの生成。
- `node --import tsx tests/api-smoke.mts`：ローカルWorker + D1で以下を確認。
  - MCPで案件作成 → 別リクエストで永続化データ取得。
  - 古いrevisionの更新を409で拒否。
  - 閲覧者のREST/MCP更新と履歴取得を拒否。別宛先の案件を取得不可。

  - 同期の排他リース、同一内容の再同期スキップ、既存イベントIDを維持した更新、古いreceipt拒否。
  - 変更履歴と会話用JSON Schema取得。
